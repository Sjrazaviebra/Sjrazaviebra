### The rule I work by

An edge that survives only the test that discovered it is not an edge, it is a memory of the data.
The same holds for a rate quoted from memory, or a dashboard that reassures instead of measuring.
Every repository here is an attempt to make a tool say *"I don't know"* out loud, on time.
